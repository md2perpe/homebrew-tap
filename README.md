# Md2perpe Tap

## How do I install these formulae?

`brew install md2perpe/tap/<formula>`

Or `brew tap md2perpe/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "md2perpe/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
